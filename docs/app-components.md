# App components

The canonical App Catalog, decision tree, import cheat sheet and architectural rules for agents live in Storybook:

- **App catalog:** `apps/storybook/src/patterns/app-catalog.mdx` (Storybook: `Patterns/App catalog`, published at `ui.manova.space`)

## Quick map

- **Introduction & escalation ladder:** `apps/storybook/src/Introduction.mdx`
- **Foundations (token-generated):** `apps/storybook/src/foundations/` (`Color roles`, `Typography`, `Spacing`, `Shape`, `Elevation`, `Motion`, `Icons`, `Density`, `Brand playground`)
- **Guidelines:** `apps/storybook/src/guidelines/` (`Forms`, `Content & microcopy`, `Accessibility`, `RTL & locale`, `Data display`, `Writing component docs`)
- **Patterns:** `apps/storybook/src/patterns/` (`App catalog`, `Entity browser`, `Field groups`, `Wizards`)
- **Component docs:** `packages/ui/src/*.mdx` (`button`, `input`, `select`, `composed/field`)
- **Page templates (experimental):** `@manovaspace/ui/experimental` (`ListPage`, `SummaryPage`, `DetailPage`, `FormSheet`) — screenshots via `bun run storybook:shots`
- **Machine-readable exports:** `packages/ui/dist/agents/index.md` (generated by `bun run --filter @manovaspace/ui gen:agent-index`)
- **Core rules:** Read `handbook/docs/orbit/guides/ui-rules.md` and `AGENTS.md`
