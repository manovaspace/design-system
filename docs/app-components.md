# App Components Catalog & Design System Standard

Visual documentation, foundations, guidelines, patterns, and component autodocs now live in **Storybook** (`apps/storybook`, published at `ui.manova.space`).
Machine-readable exports and props live in `packages/ui/dist/agents/index.md` (generated by `bun run --filter @manovaspace/ui gen:agent-index`).

## Quick map

- **Introduction & escalation ladder:** `apps/storybook/src/Introduction.mdx`
- **Foundations (token-generated):** `apps/storybook/src/foundations/` (`Color roles`, `Typography`, `Spacing`, `Shape`, `Elevation`, `Motion`, `Icons`, `Density`, `Brand playground`)
- **Guidelines:** `apps/storybook/src/guidelines/` (`Forms`, `Content & microcopy`, `Accessibility`, `RTL & locale`, `Data display`)
- **Patterns:** `apps/storybook/src/patterns/` (`Entity browser`, `Field groups`, `Wizards`)
- **Page templates (experimental):** `@manovaspace/ui/experimental` (`ListPage`, `SummaryPage`, `DetailPage`, `FormSheet`) — screenshots via `bun run storybook:shots`
- **Core rules:** Read `handbook/docs/orbit/guides/ui-rules.md` and `AGENTS.md`
